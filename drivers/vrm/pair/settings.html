Connect your installation with a VRM personal access token

Create the token in the VRM Portal:
  1. Open vrm.victronenergy.com and sign in
  2. Go to Preferences → Integrations → Access tokens
  3. Add a token, name it "Homey", and copy it right away (it is shown only once)
